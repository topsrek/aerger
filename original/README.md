# Das Original von 1995

„Mensch ärgere Dich nicht! für Windows, Version 1“ von Oliver Kraheck, erstellt mit Borland
Pascal 7 – die Shareware-Testversion, Byte für Byte unverändert. Die Hilfedatei erlaubt
ausdrücklich, diese Testversion zu kopieren und weiterzugeben.

| Datei | Inhalt |
| --- | --- |
| `AERGER.EXE` | Das Programm (16 Bit, Windows 3.1). |
| `AERGER.CFG` | Gespeicherte Einstellungen. |
| `ERGWIN.HLP` | Die Hilfedatei. |
| `GRAPH01`–`04.DAT/.IDX` | Grafiken und ihre Indexdateien. |
| `SOUNDS.DAT/.IDX` | Die 14 Klänge. |
| `BWCC.DLL` | Borland-Bibliothek für die Dialoge im 3D-Look. |
| `BEISPIEL.ERG` | Ein gespeicherter Spielstand. |

## Starten

`AERGER.EXE` ist ein 16-Bit-Programm. Es läuft unter Windows 3.1 bis Windows XP und auf
32-Bit-Ausgaben neuerer Windows-Versionen, aber nicht auf einem 64-Bit-Windows. Dort hilft
ein Emulator wie [otvdm/winevdm](https://github.com/otya128/winevdm) oder eine virtuelle
Maschine mit altem Windows.

Bequemer sind die [Web-Fassung](https://topsrek.github.io/aerger/) und die
[Windows-Portierung](../windows/README.md).

Die Registrierung, die das Programm anbietet, gibt es nicht mehr; die im Programm und in der
Hilfe genannte Anschrift und Bankverbindung sind über dreißig Jahre alt.
